# 阅标记录赋分规则确认表 - 电缆保护管 CPVC / MPP

## 适用范围

- 预审标段为“电缆保护管CPVC”或“电缆保护管MPP”时适用。
- 先根据预审标段分流，再套用对应细则。

## 当前统一口径

| 项目 | 确认口径 |
| --- | --- |
| 标准类规则 | 取最高分，不叠加 |
| 科技奖励类规则 | 取最高分，不叠加 |
| 主观项 | 先不自动计算，人工录入 |
| 运行绩效/综合绩效/质量问题/经营状况 | 先不自动计算 |
| MPP/CPVC 规则分流 | 根据预审标段决定使用 MPP 或 CPVC 对应参数规则 |
| 低于最低档阈值 | 按 0 分处理 |
