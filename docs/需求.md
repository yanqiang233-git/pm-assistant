# 项目经理助手 — 业务需求

## 一、产品定位

面向项目经理的桌面工具平台，以"项目"为核心组织单元，集成多个日常业务工具模块。

---

## 二、项目管理

### 2.1 创建项目
- 用户填写项目编号，选择项目类别（物资类 / 工程服务类），选择本地保存目录
- 系统自动记录创建日期，生成唯一 ID
- 创建后自动设为当前项目

### 2.2 最近项目
- 展示最近使用的项目列表（最多 10 条）
- 点击即可切换为当前项目
- 当前项目信息在工作台首页醒目显示

### 2.3 项目与模块关系
- 模块在当前项目的目录下工作
- 不同项目类别可使用不同的功能模块

## 三、功能模块

### 3.1 上报物资汇总表拆分（material-split）

**适用类别：** 物资类

**核心流程：** 导入 → 配置 → 拆分 → 预览 → 导出

#### 导入
- 从 Excel 文件导入上报物资汇总表数据
- 支持从剪贴板粘贴数据
- 自动校验 40 个必填字段
- 自动检测已有分包状态
- 导入成功后，自动将源文件镜像到项目目录下 `上报物资汇总表拆分/导入文件/`

#### 分包配置
- 配置拆分标段数量和各标段名称
- 每个物资行可单独选择拆分方式：平均分配 / 按比例分配 / 指定金额
- 支持全局批量设置拆分方式
- 比例模板：保存/加载/删除常用比例配置（全局共享，跨项目可用）
- 配置模板上传/下载时，自动将模板文件镜像到项目目录下 `上报物资汇总表拆分/配置模板/`

#### 拆分引擎
- 按配置对每行物资的数量和金额进行拆分计算
- 金额精度处理：以分为单位计算，确保拆分结果总和 = 原始金额
- 估算总价列自动计算

#### 预览
- 拆分结果摘要预览
- 按标段查看拆分明细

#### 导出
- 导出为多 Sheet Excel 文件，每个标段一个 Sheet
- 支持下载空白模板
- 支持导入自定义模板
- 导出时自动将结果文件镜像到项目目录下 `上报物资汇总表拆分/导出文件/`

#### 项目目录文件镜像与状态持久化
模块在打开时自动在项目目录下创建以下目录结构，并尝试恢复之前的工作状态：
```
{项目编号}_PMA/
└── 上报物资汇总表拆分/
    ├── module-state.json   ← 模块持久化状态（分标配置、拆分方式等）
    ├── 导入文件/           ← 源文件_20250619_143022.xlsx
    ├── 配置模板/           ← 分包数量配置_xxx.xlsx / 拆分方式配置_xxx.xlsx
    └── 导出文件/           ← 拆分结果_xxx.xlsx
```

**文件命名：** 采用 `{固定前缀}_{yyyyMMdd_HHmmss}.xlsx` 格式，便于辨识和排序。

**替换策略：** 用户重新导入文件或上传配置模板时，自动清理旧同类文件后写入新文件。

**自动恢复：** 同一项目下再次打开模块时：
1. 读取 module-state.json 中保存的分标配置
2. 读取导入目录中最新的源文件并重新校验
3. 校验通过后恢复导入结果和分标配置，用户可继续之前的工作
