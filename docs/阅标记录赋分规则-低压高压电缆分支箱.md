# 阅标记录赋分规则确认表 - 低压/高压电缆分支箱

## 适用范围

- 预审标段为“高压电缆分支箱”或“低压电缆分支箱（塑壳断路器）”时适用。
- 先根据预审标段分流，再套用对应细则。

## 当前统一口径

| 项目 | 确认口径 |
| --- | --- |
| 标准类规则 | 取最高分，不叠加 |
| 科技奖励类规则 | 取最高分，不叠加 |
| 主观项 | 先不自动计算，人工录入 |
| 运行绩效/综合绩效/质量问题/经营状况 | 先不自动计算 |
| 操作手柄温升 | 高压电缆分支箱直接取 4 分；低压电缆分支箱（塑壳断路器）两列分别算分后取高分 |
| 工频耐压设备缺字段 | 先空着，不写死 |
